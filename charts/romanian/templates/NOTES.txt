The current app is a single-user development scaffold, with no public authentication.
Access a test-cluster deployment through a local port forward:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "romanian.name" . }} 8080:{{ .Values.service.port }}

Then open http://localhost:8080.
No PostgreSQL instance, logical database, bucket, node, or IAM binding is created.
Create the app's dedicated database and arrange network access before installation.
